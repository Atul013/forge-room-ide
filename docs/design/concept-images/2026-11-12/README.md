## Generation brief

Generated with the built-in image generation tool using one prompt per image. Each prompt requested a polished, high-fidelity UI concept for the named section, a native Forge Room interface, dark graphite with restrained warm ember accents, readable hierarchy, and no in-app AI assistant. Prompts for communication and service screens requested honest offline or availability states rather than implied live connectivity. The first eleven assets use desktop layouts; the last explores mobile screens beside a desktop view.

The image filenames map to the prompts' section names above. These images are for visual direction only. Validate labels, interactions, accessibility, and capability claims in native UI code before adopting any detail.
