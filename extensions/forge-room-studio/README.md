# Forge Room Studio

Forge Room Studio contributes six native Code OSS themes: Neon Ronin, Starship Deck, Moss Shrine, Ink & Ember, Paper Studio, and Signal Guard high contrast. The gallery previews each palette card. Selecting Apply temporarily changes the workbench, then asks you to keep that theme or restore the saved appearance. Dismissing the choice restores the previous settings. **Restore Previous Appearance** remains available after you keep a theme.

Use **Forge Room: Create Custom Color Palette** to choose editor background/text, selection background, and accent colors for the activity and status bars. Studio checks editor text and accent contrast, shows a live preview, and can restore the prior colors. The six bundled themes are regression-tested for at least 4.5:1 contrast across core workbench and syntax text, plus 3:1 for focus borders and inactive activity icons. **Forge Room: Customize Syntax Colors** sets seven common token scopes: comments, strings, keywords, numbers, functions, types, and variables. Studio checks contrast against the active editor background and offers a live preview with restore.

Use **Forge Room: Export Project Profile** and **Forge Room: Import Project Profile** to save or apply a local JSON profile. Profiles include allowlisted appearance settings (theme, supported workbench colors and syntax scopes, file/product icon themes, editor font family and size) and editor preferences (tab size, spaces, wrapping, minimap, whitespace, line numbers, and rulers). Import validates every value, previews the profile live, then offers **Keep Profile** or **Restore Previous**. Canceling or dismissing the choice restores prior settings. Applying a profile overlays its supported colors and syntax scopes while preserving unrelated customizations. Older appearance-only version 1 profiles remain importable. Profiles cannot install extensions, modify keybindings, alter agent permissions, or include executable code.

Theme source files are ordinary Code OSS color theme JSON under `themes/`. Studio assets are bundled locally; preview artwork uses CSS. Decorative motion is off by default and can be enabled with the gallery Motion control. The preference survives webview reloads; the operating system reduced-motion setting always suppresses it.

## Portable custom theme bundles

Use **Forge Room: Export Custom Theme Bundle** to save the current supported color and syntax overrides as a named JSON file. Use **Forge Room: Import Custom Theme Bundle** to validate and preview one at user or workspace scope, then keep or restore it. The bundle supports 12 allowlisted workbench color IDs and seven common TextMate scopes. Import merges only those properties, preserves unrelated settings, leaves the active base theme selected, and asks before applying. Low foreground contrast is called out. Arbitrary theme IDs, extension installation, scripts, icons and unsupported colors are not imported.
